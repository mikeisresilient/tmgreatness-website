## 📖 Overview

TMGreatness is a dance and entertainment brand known for delivering exceptional performances and inspiring audiences through creativity and passion.

This project transforms the brand's identity into a visually appealing and interactive website that provides visitors with an immersive experience while making it easy to explore performances, achievements, and booking information.

---

## 🚀 Live Demo

🔗 **https://tmgreatness-website.vercel.app/**

---

## ✨ Features

- Modern and elegant user interface
- Fully responsive across desktop, tablet, and mobile devices
- Smooth animations powered by Framer Motion
- Interactive portfolio gallery with lightbox
- Statistics section highlighting achievements
- Brand journey timeline
- Contact and booking section
- Clickable social media integration
- Optimized WebP images for improved performance
- Clean and reusable React component architecture

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/mikeisresilient/tmgreatness-website.git
```

Navigate into the project

```bash
cd tmgreatness-website
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open

```
http://localhost:5173
```

---

## 📦 Production Build

Create an optimized production build

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```
